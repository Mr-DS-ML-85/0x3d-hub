How to Use This Dashboard

This is a LOCAL editor for your STATIC website.

This dashboard allows you to edit the content of your website directly on your computer. It is not connected to your live, public website. To make your changes appear online, you must deploy them (e.g., using 'git push').

Core Workflow:

  1. Connect to Folder: Click the "Connect Folder" button in the sidebar. You MUST select the project's ROOT folder (the one containing `index.html`, `admin/`, and `content/`). The status indicator will turn green and show the folder name when connected.
  2. Edit Content: Navigate to a section like "Posts" or "Languages". Click "New Post" or "Edit" to make your changes.
  3. Save Your Changes: Click the "Save" button in the editor. This will write the changes directly to the JSON and Markdown files in your local project folder.
  4. (IMPORTANT) Deploy Your Site: The changes are only on your local computer. You need to use your normal deployment process (like `git add .`, `git commit`, and `git push`) to update your public website.

Common Issues:

  • "My changes aren't on the website!": You must complete Step 4 (Deploy) for changes to appear online.
  • Saving doesn't work: Make sure you are using a compatible browser (Chrome or Edge are recommended). Brave Browser's "Shields" may block file saving.
  • "No new blog upload option": The button is on the "Posts" panel, labelled "+ New Post".
