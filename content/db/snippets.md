# Code Snippets
Useful code fragments and highlighting tools for your projects.

## Highlighting Tools
- [Highlight.js](https://highlightjs.org/) - Syntax highlighting for the Web. Supporting 190+ languages and 90+ themes.
- [PrismJS](https://prismjs.com/) - Lightweight, robust, elegant syntax highlighting. Used by many big sites.

## CSS Generators
- [Glassmorphism Generator](https://markodenic.com/tools/glassmorphism-css-generator/) - Use Glassmorphism Generator to create a stunning effect for your projects.
- [Buttons Generator](https://markodenic.com/tools/buttons-generator/) - An online gallery of 100+ button designs you can easily copy and use in your projects.
- [Layoutit Grid](https://grid.layoutit.com/) - Quickly design web layouts, and get HTML and CSS code. Learn CSS Grid visually.
- [CSS Gradient Editor](https://cssgradienteditor.com/) - You may only need this tool for creating CSS gradients and patterns.
- [Hola SVG Loaders](https://holasvg.com/loaders/) - SVG Loaders Generator with Sass and SMIL options.
- [Shape Divider](https://www.shapedivider.app/) - Export a beautiful SVG shape divider for your latest project.
- [Neumorphism](https://neumorphism.io/) - A free online tool for designing attractive UI with colors, gradients and shadows.
- [Scrollbar.app](https://scrollbar.app/) - A simple online tool for creating custom scrollbars for the web.
