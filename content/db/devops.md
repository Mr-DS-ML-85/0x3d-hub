# Devops Resources

Infrastructure as code, Docker, Kubernetes, and seamless automation pipelines.

## Cloud Platforms
- [AWS Home](https://aws.amazon.com) - Official Amazon Web Services landing page.
- [Azure DevOps Documentation](https://docs.microsoft.com/en-us/rest/api/azure/devops) - REST API references for Azure DevOps.
- [Azure DevOps Health](https://docs.microsoft.com/en-us/rest/api/resourcehealth) - Monitoring API for Azure resource health.
- [Google Cloud Based Online Courses](https://www.coursejoiner.com/freeonlinecourses/google-cloud-based-online-courses/) - Free GCP training resources.

## Containers & Orchestration
- [Docker Hub API](https://docs.docker.com/docker-hub/api/latest/) - Documentation for Docker Hub integration.
- [Kubernetes Made Easy - A Beginners Guide](https://blog.bytebytego.com/p/kubernetes-made-easy-a-beginners) - Simple introduction to K8s concepts.
- [From Docker To Kubernetes A Beginners Guide](https://content.techgig.com/career-advice/from-docker-to-kubernetes-a-beginners-guide-to-devops-world/articleshow/116745073.cms) - Path from containerization to orchestration.
- [Top 10 Resources To Learn Kubernetes In 2025](https://dev.to/somadevtoo/top-10-resources-to-learn-kubernetes-k8-in-2025-3nbj) - Curated learning path for K8s.
- [4 Tiny Docker Images For Lightweight Containers](https://www.infoworld.com/article/3804073/4-tiny-docker-images-for-lightweight-containers.html) - Optimization guide for container size.
