# Security

## General
- [Application Environment Verification](https://github.com/fingerprintjs/aev) - Android library and API to verify the safety of user devices, detect rooted devices and other risks.
- [BinaryEdge](https://docs.binaryedge.io/api-v2.html) - Provide access to BinaryEdge 40fy scanning platform.
- [BitWarden](https://bitwarden.com/help/api/) - Best open-source password manager with a robust API.
- [Censys](https://search.censys.io/api) - Search engine for Internet connected host and devices.
- [EmailRep](https://docs.emailrep.io/) - Email address threat and risk prediction.
- [GitGuardian](https://api.gitguardian.com/doc) - Scan files for secrets (API Keys, database credentials) to prevent data leaks.
- [HackerOne](https://api.hackerone.com/) - The industry’s first hacker API for bug bounty hunting productivity.
- [HaveIBeenPwned](https://haveibeenpwned.com/API/v3) - Check if passwords or emails have been previously exposed in data breaches.
- [MSRC API](https://msrc.microsoft.com/report/developer) - Programmatic interfaces to engage with the Microsoft Security Response Center.
